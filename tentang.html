Beranda Tentang

Tentang Proyek

Astral Gacha adalah simulator gacha fan-made bertema fantasi. Pengguna menarik kartu dari satu banner dengan dua pilihan: Tarik x1 atau Tarik x10. Setiap kartu memiliki rarity 3★, 4★, atau 5★ yang ditentukan secara acak.

Website ini dibuat untuk UTS mata kuliah Pemrograman Web menggunakan HTML, CSS, dan JavaScript murni, tanpa framework dan tanpa backend.

Tabel Rate

Rarity Peluang Keterangan
5★ 0,8% Dijamin di pull ke-80 lewat pity
4★ 12% Peluang tetap setiap pull
3★ 87,2% Sisanya dari total 100%

Penjelasan Pity

Counter pity bertambah 1 setiap kali melakukan pull. Jika counter mencapai 80, pull berikutnya dijamin mendapatkan karakter 5★. Setelah mendapat 5★ (baik dari pity maupun keberuntungan), counter kembali ke 0.
